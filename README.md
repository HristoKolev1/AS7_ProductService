# Product Service

Product management service for the **Enterprise E-commerce Platform**, a webshop focused on technical products such as laptops and computer accessories.

The service is responsible for managing the product catalogue and exposing product-related functionality to the rest of the platform.

## Responsibilities

- Product catalogue management
- Product information retrieval
- Product-related REST API operations
- Integration with shopping cart and order functionality

## Tech

Java · Spring Boot · REST APIs

## Enterprise E-commerce Platform

This service is part of a larger microservices-based e-commerce system.
